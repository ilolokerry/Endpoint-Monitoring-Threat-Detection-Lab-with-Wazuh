
# 🛡️ Hands-On Lab 5 – Detecting Malicious Files with Wazuh & VirusTotal

---

# 📌 Overview

This hands-on lab demonstrates how Wazuh can integrate with Virustotal to detect malicious files on monitored Linux endpoints.

The lab focused on:
- Monitoring file activity using File Integrity Monitoring (FIM)
- Creating custom Wazuh rules
- Integrating VirusTotal with Wazuh
- Generate malware detection alerts in the SIEM

---

# 🧠 What is VirusTotal?

Virustotal is an online threat intelligence and malware analysis platform 

It analyzes files, URLs, domains, and IP addresses using multiple antivirus engines and threat intelligence sources to identify malicious content.

---

 ⚙️ VirusTotal Capabilities

-  Malware file scanning
-  URL and domain reputation analysis
-  Threat intelligence aggregation
-  Malicious hash detection
-  File reputation analysis
-  Security investigation support

 File Integrity Monitoring Configuration

Before starting this lab, File Integrity Monitoring (FIM) was enabled on the Wazuh agent for the `/root` directory.

## Wazuh Agent Configuration

Open the Wazuh agent configuration file:

```bash
sudo nano /var/ossec/etc/ossec.conf
```

---

Syscheck Configuration

```xml
<syscheck>
  <directories realtime="yes">/root</directories>
</syscheck>
```

This configuration enables real-time monitoring of the `/root` directory for file additions and modifications.


# Step 1 – Create Custom Wazuh Rules

The Wazuh web interface was used to create custom detection rules for monitoring file activity inside the `/root` directory.

---

 Navigate to Local Rules

Within the Wazuh dashboard:
- Navigate to **Rules**
- Search for **Local Rules**
- Open the local rules editor
- Add Custom Rules

```xml
<group name="syscheck,pci_dss_11.5,nist_800_53_SI.7,">

    <!-- Rules for Linux systems -->

    <rule id="100200" level="7">
        <if_sid>550</if_sid>
        <field name="file">/root</field>
        <description>File modified in /root directory.</description>
    </rule>

    <rule id="100201" level="7">
        <if_sid>554</if_sid>
        <field name="file">/root</field>
        <description>File added to /root directory.</description>
    </rule>

</group>
```
These custom rules generate alerts whenever files are added to or modified inside the `/root` directory. The rules help monitor sensitive locations and trigger VirusTotal scanning for suspicious file activity.

#  Step 2 – Integrate VirusTotal with Wazuh

VirusTotal integration was configured within the Wazuh manager configuration.

---

## Open Wazuh Manager Configuration

```bash
sudo nano /var/ossec/etc/ossec.conf
```

---

Add VirusTotal Integration

```xml
<ossec_config>
  <integration>
    <name>virustotal</name>
    <api_key>YOUR_VIRUSTOTAL_API_KEY</api_key>
    <rule_id>100200,100201</rule_id>
    <alert_format>json</alert_format>
  </integration>
</ossec_config>
```
This configuration connects Wazuh to VirusTotal using an API key and automatically scans files associated with alerts generated by Rules `100200` and `100201`.

#  Step 3 – Download Sample Malware File

A malware test file from the eicar. website was downloaded into the monitored `/root` directory.

---

 Download EICAR Test File

```bash
sudo curl -Lo /root/eicar.com https://secure.eicar.org/eicar.com && sudo ls -lah /root/eicar.com
```

The EICAR file is a harmless test file designed to simulate malware detection behavior safely.
